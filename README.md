# AI 模型目录

基于 Pi 的 AI 模型与价格目录，可按供应商和上下文筛选、比较价格、查看 SOTA 旗舰和复制 API 接入地址。

[打开站点](https://ai-models.wangruofeng007.com/) · [更新日志](https://ai-models.wangruofeng007.com/changelog.html)

## 本地运行

```bash
npm install
npm run dev
```

打开 <http://localhost:3456>。站点使用原生 HTML、CSS 和 JavaScript，发布无需构建。

## 数据

最近同步：2026-11-26。pi.dev/models 源站共 1696 个模型，另保留 145 个官方补充条目，合计 1841 个模型、47 个 provider。
